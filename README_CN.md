## 推荐研究环境

请不要直接在：

- 个人主力电脑
- 公司生产服务器
- 实验室生产环境
- 含真实账号的设备
- 含敏感文件的设备
- 公网生产网络

中直接运行来源未知的恶意软件。

推荐使用：

```text
Malware Sample
      │
      ▼
Isolated VM
      │
      ├── Snapshot
      ├── No Personal Credentials
      ├── Restricted Network
      ├── Traffic Capture
      ├── Process Monitoring
      ├── File Monitoring
      └── Disposable Environment
```

建议至少使用：

- 独立虚拟机
- 快照
- Host-Only 网络
- NAT 隔离
- 网络流量监控
- DNS 监控
- 进程监控
- 文件系统监控
- 注册表监控
- 禁止真实凭据进入研究环境
- 必要时完全断网分析
